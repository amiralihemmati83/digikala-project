# پروژه دیجی کالا

طراحی صفحه اصلی و صفحه شگفت انگیز سایت دیجی کالا با HTML و CSS

## صفحه ها

- `index.html` : صفحه اصلی
- `amazing.html` : صفحه پیشنهاد شگفت انگیز

## تکنولوژی ها

- HTML
- CSS
- JavaScript (برای اسلایدر ها)
- [Swiper](https://swiperjs.com/) برای اسلایدر ها
- [Remix Icon](https://remixicon.com/) برای آیکون ها
- فونت وزیرمتن

## اجرا

کافیه فایل `index.html` رو توی مرورگر باز کنید (یا با Live Server).

فایل های swiper توی پوشه `lib/swiper` کپی شدن، برای همین بدون `npm install` هم پروژه کار میکنه.
اگه خواستید پکیج ها رو هم نصب کنید:

```
npm install
```

## ساختار پوشه ها

```
css/       فایل های css (هر بخش یه فایل جدا، همه توی main.css ایمپورت شدن)
js/        فایل های جاوا اسکریپت
images/    عکس ها
fonts/     فونت ها
lib/       swiper و آیکون ها
```
